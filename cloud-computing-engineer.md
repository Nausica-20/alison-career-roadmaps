## 📋 Career Overview

Design and manage cloud-based systems and infrastructure for scalable computing solutions.

### Salary Expectations
- **Entry Level:** $$75,000 - $100,000/year
- **Mid Level:** $$100,000 - $140,000/year
- **Senior Level:** $$140,000 - $190,000+/year

### Job Market Outlook
📈 **Excellent**

## 🗺️ Learning Roadmap

### PHASE 1: Foundation (Beginner) - 6-8 hours

#### Course 1: Cloud Computing for Absolute Beginners
- **Duration:** 2-3 hours
- **Topics:** Cloud basics, IaaS model, key terms
- **Link:** [Cloud Computing for Absolute Beginners](https://alison.com/course/cloud-computing-for-absolute-beginners-iaas)

#### Course 2: Cloud Database Technologies and Services
- **Duration:** 2-3 hours
- **Topics:** DBaaS, Azure, AWS, GCP
- **Link:** [Cloud Database Technologies and Services](https://alison.com/course/cloud-computing-database-technologies-and-services)

---

### PHASE 2: AWS Fundamentals (Intermediate) - 6-8 hours

#### Course 1: Amazon Web Services: Basic
- **Duration:** 2-3 hours
- **Topics:** AWS introduction, core services
- **Link:** [Amazon Web Services: Basic](https://alison.com/tag/aws)

#### Course 2: Amazon Web Services: Intermediate
- **Duration:** 2-3 hours
- **Topics:** Advanced AWS features
- **Link:** [Amazon Web Services: Intermediate](https://alison.com/tag/aws)

---

### PHASE 3: AWS Specialization (Advanced) - 16-20 hours

#### Course 1: Diploma in Amazon Web Services
- **Duration:** 8-10 hours
- **Topics:** AWS platform, security, pricing, support
- **Link:** [Diploma in Amazon Web Services](https://alison.com/course/diploma-in-amazon-web-services)

#### Course 2: Advanced Diploma in Cloud Computing for AWS
- **Duration:** 8-10 hours
- **Topics:** EC2, AMI, disaster recovery, SSH, S3, CLI
- **Link:** [Advanced Diploma in Cloud Computing for AWS](https://alison.com/course/advanced-diploma-in-cloud-computing-for-amazon-web-services)
