# Contributing to Alison Career Roadmaps

Thank you for your interest in contributing! We welcome contributions from the community.

## How to Contribute

### Reporting Issues
- Use GitHub Issues to report problems
- Provide clear descriptions of the issue
- Include steps to reproduce if applicable

### Suggesting Enhancements
- Open an issue with the "enhancement" label
- Describe your suggestion clearly
- Explain why it would be useful

### Submitting Changes

1. **Fork the Repository**
   ```bash
   git clone https://github.com/yourusername/alison-career-roadmaps.git
   ```

2. **Create a Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make Your Changes**
   - Update documentation
   - Add new courses
   - Fix broken links
   - Improve content

4. **Test Your Changes**
   - Verify all links work
   - Check markdown formatting
   - Ensure consistency with existing content

5. **Commit Your Changes**
   ```bash
   git add .
   git commit -m "Description of your changes"
   ```

6. **Push to Your Fork**
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Create a Pull Request**
   - Go to the original repository
   - Click "New Pull Request"
   - Describe your changes
   - Wait for review

## Types of Contributions We Need

### Content Updates
- **Update Course Links** - Fix broken or outdated links
- **Add New Courses** - Include relevant courses from Alison
- **Update Salary Information** - Keep salary ranges current
- **Improve Descriptions** - Make content clearer and more helpful

### New Roadmaps
- Research the career thoroughly
- Follow the existing format
- Include practical advice
- Add relevant resources

### Documentation
- Fix typos and grammar
- Improve clarity
- Add examples
- Create guides

### Translations
- Translate roadmaps to other languages
- Maintain formatting consistency
- Keep technical terms accurate

## Style Guide

### Markdown Formatting
- Use consistent heading levels
- Include links where helpful
- Add emojis for visual appeal (sparingly)
- Keep lines under 120 characters when possible

### Content Style
- Write clearly and concisely
- Use bullet points for lists
- Include practical examples
- Keep tone friendly and encouraging

### Link Format
- Use descriptive link text
- Verify links work before submitting
- Use HTTPS when available
- Link directly to specific courses

## Code of Conduct

### Our Standards
- Be respectful and inclusive
- Welcome newcomers
- Accept constructive criticism
- Focus on what's best for the community

### Unacceptable Behavior
- Harassment or discrimination
- Trolling or insulting comments
- Spam or promotional content
- Publishing others' private information

## Questions?

If you have questions about contributing:
- Open an issue with the "question" label
- Check existing issues for answers
- Be patient and respectful

## Recognition

Contributors will be recognized in our README. Thank you for helping make education more accessible!
